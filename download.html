Verify your download

Every release publishes a SHA-256 fingerprint. Check it before you open the app. If it doesn't match, delete the file.

Terminal
shasum -a 256 ~/Downloads/Astrala-Wallet.dmg
It should printpublished with each release
Go further: rebuild the engine and compare it with the app

The code that holds your keys and makes every network request is public. Build it and its fingerprint matches the engine inside the app you downloaded, byte for byte.

git clone <source repository> && cd astrala-engine
npm ci && npm run build
shasum -a 256 out/main/index.js out/preload/index.cjs

npx @electron/asar extract "/Applications/Astrala Wallet.app/Contents/Resources/app.asar" /tmp/astrala-app
shasum -a 256 /tmp/astrala-app/out/main/index.js /tmp/astrala-app/out/preload/index.cjs

Both pairs of fingerprints must be identical.

Astrala in your browser

A Chrome extension that works two ways: as a remote for the Astrala app, or as a wallet on its own.

With the Astrala app

With the app installed, the extension is a remote for the app. Your keys stay in the app.

Only in the app

  • Monero
  • Routing through Tor or Mullvad
  • Hardware wallets
  • The duress PIN
  • Swaps, Split and Route
  • Connecting to websites
  • Touch ID

On its own Beta

Without the app, for example on Windows today, the extension can be a wallet by itself. You create or import a wallet in Chrome, and the keys are stored encrypted in that browser.

What it supports

  • Bitcoin, Ethereum and its networks, Solana, Litecoin
  • Receive and send
  • A 6-digit PIN on every payment
your browser

Get the extension

Works in Chrome, Edge, Brave, Opera and Vivaldi on Windows, Mac and Linux.

Download the extension (.zip)
Not it?
  1. Unzip the download.
  2. Open chrome://extensions in Chrome, Edge or Brave.
  3. Switch on "Developer mode" (top right).
  4. Click "Load unpacked" and choose the unzipped folder.

Installed outside a store, so your browser shows a "developer mode" reminder — that's expected. Free one-click installs are on the way (Edge Add-ons and a signed Firefox build).

Windows and Linux

On Windows and Linux you can use Astrala today through the browser extension. The full desktop app for Windows and Linux is on the way.
